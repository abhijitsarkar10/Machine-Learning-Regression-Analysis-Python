# Machine-Learning-Regression-Analysis-Python
Python machine learning projects for refurbished car price prediction and concrete strength prediction using Linear Regression and Random Forest.

## Project Overview

This project demonstrates regression-based machine learning using two real-world datasets.

The first project predicts refurbished car prices using Multiple Linear Regression.

The second project predicts concrete compressive strength using Linear Regression and Random Forest Regression.

## Project 1 — Refurbished Car Price Prediction

### Objective
Predict the price of refurbished cars based on available vehicle features.

### Techniques
- Data Cleaning
- Exploratory Data Analysis
- Categorical Encoding
- Train-Test Split
- Multiple Linear Regression
- Model Evaluation
- Actual vs Predicted Visualization

### Evaluation Metrics
- MAE
- MSE
- R² Score

## Project 2 — Concrete Strength Prediction

### Objective
Predict concrete compressive strength using its material and age-related features.

### Models
- Linear Regression
- Random Forest Regression

### Analysis
- Missing Value Analysis
- Correlation Analysis
- Model Evaluation
- Feature Importance

### Evaluation Metrics
- MAE
- RMSE
- R² Score
